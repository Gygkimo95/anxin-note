# 安心手记 0.5.4

这一版让提醒更私密，也更符合每个人的服药节奏。

## 更新内容

- 普通服药提醒不再显示药名或剂量，只显示通用的温和提示。
- 后台常驻通知不再显示药名，只显示下一次提醒时间。
- 可统一选择准时或提前 5/10/15/30 分钟提醒。
- 设置页会显示下一次实际提醒时间和当前提前量。

## 安装

- 已安装 0.5.3 正式版：直接覆盖安装，记录会保留。
- 仍在使用早期 Debug 测试版：请先备份，再卸载旧版并安装正式版。
- 升级前建议确认 `下载/安心手记/安心手记-备份.json` 存在。

本应用不提供医疗建议，补服和剂量调整请遵循医生或药师指导。
