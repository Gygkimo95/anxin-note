# 我做了一个不打卡、不联网的服药与压力记录工具

> 备选标题：不算连续天数，也不评价你：安心手记 Android 内测招募

治疗期间，有两类信息很容易在一天里消失。

一种是很具体的：“今天这顿药到底吃了没有？”另一种更模糊：压力起来的那一刻，
身体是什么反应、脑子里反复出现什么、后来做了什么才慢慢缓下来。

通用的待办和习惯 App 可以提醒，却常常还带着连续天数、完成率、红点和“中断”
提示。对一些人来说，这些指标不是帮助，而是第二种压力。

所以我做了安心手记。它目前是一个 Android 本地应用，只认真做三件事。

## 第一件事：回答“这顿药吃了没”

首页把同一时间需要吃的药合成“一顿”。不论这一顿是一种还是几种药，都只需要
点一次“吃了”或“都吃了”。通知上也可以直接确认，不必先打开 App。

记录的是实际确认时间，而不只是计划时间。没有记录的日子保持空白，不显示
“漏服”“失败”，也不统计连续天数或服药率。

提醒采用静默横幅：会弹出来，但不发声、不震动。Android 厂商对后台应用的限制
差异很大，安心手记会在提醒开启时自动保持后台运行，并在开机后恢复排程。

> 配图建议：首页当前一顿的大卡片、最近七天状态、系统服药通知。

## 第二件事：压力起来时，30 秒留住现场

压力很高的时候，完整复盘通常是不现实的。因此第一次记录只有三件事：

- 发生了什么，可以不写；
- 现在有多难受；
- 身体有什么反应。

写不了文字，只拉一下强度也可以。它不会要求当场分析原因，更不会催着立即解决。

> 配图建议：“现在怎么了”页面，突出“写不了就只拉个强度，够了”。

## 第三件事：事后补成自己的应对手册

等状态过去一些，再回来补“当时在想什么”“做了什么”“现在还剩多少”。

这些记录最后会组成一份个人应对手册。它统计的是某种方法使用过几次、平均让强度
下降多少，而不是给人打分。只用过一次的方法会明确写“才一次，先别当结论”。

这是我很想坚持的一条原则：可以统计方法，不统计人。

> 配图建议：“后来呢”和“应对手册”页面。

## 为什么可以相信它不上传

安心手记没有账号、云同步、广告或统计 SDK，也没有申请 Android 的
`INTERNET` 权限。不是在隐私政策里承诺“不上传”，而是安装包本身没有联网能力。

记录保存在手机应用私有目录，同时自动备份到 `下载/安心手记/`。备份是普通 JSON
文件，用户可以自己保管、迁移和检查。源码以 GPL-3.0 公开，Manifest 和构建配置
都可以直接核对。

源码：<https://github.com/Gygkimo95/anxin-note>

隐私说明：<https://github.com/Gygkimo95/anxin-note/blob/main/PRIVACY.md>

这里也有两个需要坦白的边界：

- 服药通知可能显示用户填写的药名和剂量，请根据自己的锁屏隐私设置决定是否展示；
- 备份位于共享的下载目录，应像其他健康资料一样妥善保管。

## 它刻意不做什么

安心手记不是医疗器械，不判断是否应该补服，也不提供剂量调整建议。这些问题只能
遵循医生或药师的指导。

当前版本也不支持 iOS、云同步、复杂的“每周几服用”方案和按需救援药记录。它首先
服务的是每天按固定时间服药、希望把记录留在本机的 Android 用户。

## 现在希望测试什么

0.5.3 是第一个公开内测版本。核心页面、Android 14 模拟器提醒、vivo 真机安装和
备份恢复已经跑通，但 Android 的后台策略高度碎片化，我尤其希望得到这些反馈：

1. 不同品牌手机在退到桌面、锁屏和过夜后，提醒是否仍按时出现；
2. 通知上的“吃了”能否正确回写首页；
3. `下载/安心手记/` 是否正常生成备份，重装后能否恢复；
4. 哪些文案或状态反而制造了额外压力；
5. 多种药、一天多次时，“按顿组织”是否符合实际使用习惯。

如果反馈问题，请附上手机品牌、Android 版本、是否开启通知/自启动/后台不受限，
以及问题发生的大致时间。不要公开附带包含真实健康记录的备份文件。

## 下载与安装

系统要求：Android 7.0 及以上。

下载地址：<https://github.com/Gygkimo95/anxin-note/releases/tag/v0.5.3>

首次安装需要允许文件管理器“安装未知应用”。以后升级请直接覆盖安装，不要先卸载。
卸载会删除应用私有目录中的记录；换机或重装前，请先确认
`下载/安心手记/安心手记-备份.json` 存在。

如果你安装过此前的 Debug 测试包，因为正式版签名不同，需要先在旧版中备份，
再卸载旧版、安装 0.5.3，并在首次页面选择“已有备份？从备份恢复”。这是一次性
迁移，从 0.5.3 开始后续版本可以直接覆盖升级。

问题与建议可以提交到：
<https://github.com/Gygkimo95/anxin-note/issues>

我希望它最终只是一个安静、可靠的工具：需要的时候出现，记下事实，然后退回去。
