# 安心手记 0.5.3 · 首个公开内测版

安心手记是一个完全离线的 Android 服药与压力记录工具。

## 这一版

- 按“顿”记录服药，通知上可直接确认。
- 压力速记与事后补完，逐步形成个人应对手册。
- 静默服药提醒，并针对 Android 后台限制自动保持运行。
- 数据仅保存在手机，自动备份到 `下载/安心手记/`。
- 首次安装可直接从备份恢复。

## 安装与升级

- 支持 Android 7.0 及以上。
- 下载 `anxin-note-0.5.3.apk` 后，通过文件管理器安装。
- 首次安装可能需要允许“安装未知应用”。
- 后续版本请直接覆盖安装，不要先卸载。

### 此前 Debug 测试用户

0.5.3 改用正式签名，无法直接覆盖 Debug 版。请先：

1. 在旧版中立即备份。
2. 确认 `下载/安心手记/安心手记-备份.json` 存在。
3. 卸载旧版，安装本版本。
4. 在首次页面选择“已有备份？从备份恢复”。

## 重要说明

- 本应用不提供医疗建议，补服和剂量调整请遵循医生或药师指导。
- 服药通知可能显示用户填写的药名和剂量。
- 公开内测重点是不同 Android 品牌的后台提醒与备份可靠性。
